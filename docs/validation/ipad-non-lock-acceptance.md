# 2026-10-05 非锁屏补充验收

用户取消后续物理锁屏项目，要求把当前模拟能完成的检查做完。本轮以 main `da2d0aa` 的既有 guest 和 IPA 为基线，在 Linux/QEMU 的新临时盘、iPad Simulator 的独立菜单夹具，以及独立真机 UI runner 上验证。没有重打包、重装正式 App、卸载正式 App、操作 LinuxPrototype 或读取原 raw 用户盘。

**发现并修复两个源码缺口，但修复尚未进入当前已安装 IPA。** 真实长后台故障根因仍未确认，[Issue19](https://github.com/lvivvde/deepseek-harness-ipad/issues/19) 保持开放；8 小时及后续锁屏项目按用户要求取消，不计通过。先前真机的证据和限度见 [后台恢复记录](ipad-background-recovery.md)。

Vite 最初的 HMR 失败在测试启动方式调整后消失：开发服务器改为非交互模式、标准输入来自 `/dev/null`，不再继承串口；同时清除了编译缓存环境。两项同时调整，未单独证明哪一项是原因，不据此修改生产转发代码。最初失败、包版本锁文件、后续 WS 事件和超时日志均保存在本地。

Web 模拟的第一版端点覆盖没有生效，合成占位 Key 得到 AUTH 失败；不登记为正式 App 的 API 故障。修正为在新临时 guest 的 Web 进程启动时显式传入本地端点后，前端和服务端闭环通过。第一轮逐字符终端输入未完成执行，只看到回显；Ctrl+C 清行后以真实文本粘贴和 Enter 复测，并读取受控标记文件证明执行。未把输入回显误记为终端通过。

宿主 allocated 最后一组测量为：写入前 112,832,512 字节，写入后 179,941,376 字节，删除/trim 后 182,804,480 字节。后台小量写入会影响差值；本轮只能说没有观察到宿主回收，不将 guest 可用空间与宿主 raw 占用混为一谈。

## 两个修复

1. 原生项目行的 UIButton 在弹出菜单时隐藏自身呈现，项目文字随之消失，但辅助功能节点仍存在。保留独立 SwiftUI 行标签，UIKit 透明按钮只负责锚定菜单和动作；项目和回收站行均做浅色/深色截图 OCR。测试独立于 QEMU 与正式用户数据，保存在 [原生菜单回归说明](../../ios/HarnessApp/UITests/NativeMenu/README.md)。
2. 示例 `ipad-hello-plugin` 原先挂在提供 Agent 注册表的插件子分支下，其工具未进入实际 Agent 的模型面。改为与内置工具同层的 root 插件贡献。旧 guest 包在模型验收中明确报 `PLUGIN_NOT_ADVERTISED_TO_MODEL`；向新临时盘注入当前示例源码后，声明、执行及结果返回均通过。既有用户示例和 profile 不被自动覆盖；已经安装的旧示例仍需后续有意识地更新，不能把源码修复当作当前 iPad 已修复。

## 真机上没有破坏数据的补充观察

同一个已安装包的应用设置能看到逻辑容量、已分配占用、iPad 可用空间，以及备份/恢复入口。恢复入口在下方滚动区域，不能因首屏未出现就判断缺失。旋转后的输入区域可见，横屏约 730×37、竖屏约 708×37；中文测试草稿曾实际显示。最后一次检查保护非空输入，没有发送额外消息或清掉不能确定属于测试的草稿。

这些观察不证明真实低空间情形、完整硬件键盘/中文候选与组合输入、所有项目/配置/Git 历史/插件逐项完好，也不证明删除后宿主占用下降。原用户确认的未丢输入、正常回复与流式输出，以及先前约 30 分钟锁屏后的已有会话请求证据继续保留。

## 可复现命令

```sh
make test-app
make test-runtime
make check
# Linux；既有正式 guest 目录，但只新建临时用户盘。
python3 runtime/tests/boot-acceptance.py /path/to/guest
python3 runtime/tests/boot-acceptance.py /path/to/guest --recovery-only
# 默认检查包内旧示例；修复前的旧包应明确失败。
python3 runtime/tests/boot-acceptance.py /path/to/guest --plugin-model-only
# 验证当前示例源码，仅复制到本轮新临时盘。
python3 runtime/tests/boot-acceptance.py /path/to/guest --plugin-model-only \
  --plugin-source runtime/guest/examples/hello
# macOS，指定已经启动的 iPad Simulator；不选择真机。
python3 ios/HarnessApp/scripts/test-native-menu.py \
  --simulator <booted-Simulator-UUID> --output /tmp/native-menu-new
```

CLI 只报告固定诊断和结果，串口、完整请求及设备日志不公开。合成提供者不会调用真实 API，也不会无限要求未声明的工具。隔离实验的 raw 盘、浏览器、转发服务和 Git daemon 在结束后关闭。
