# 恢复、备份与一次集中验收

对应 [前后台恢复、用户数据救援与重签交付验收](https://github.com/lvivvde/deepseek-harness-ipad/issues/19)，与 [插件、端口预览和终端辅助键](https://github.com/lvivvde/deepseek-harness-ipad/issues/23) 一起交付测试，避免反复打包与安装。

## 已实现

- 嵌入 QEMU 的串口与 QMP 使用预先连接的 Unix socketpair，设置 SO_NOSIGPIPE；页面转发可单独修复。回到前台先确认 VM，再通过串口检查 Harness、用户盘可写性、备份占用状态，并完成两阶段宿主时间握手。连接恢复设 10 秒截止；时间校验容差 2 秒，真机耗时仍需验证。
- 页面进程退出重载官方入口。Harness 退出可在旧实例及写入者确认退出后重启；单次页面超时不重启 VM。VM 真正退出要求重开 App。故障页提供诊断和数据救援，诊断只记录固定事件。
- 用户主动发起完整 tar 备份或恢复；写入者协调后冻结 ext4 导出，结束后解冻并启动 Harness。控制服务不使用用户盘编译缓存，冻结时健康探测直接返回占用状态，不写探测文件。独立看门狗在传输进程被杀时解冻；备份租约到期可恢复 Harness。开发服务器和工具任务不会自动续跑。
- 完整备份含用户配置、会话、项目、回收站、插件 profile 与离线包缓存；排除 node_modules、.cache、.git-credentials、恢复救援目录及正在清理的回收站目录。SHA256 不匹配时不上传。归档需通过路径、链接、类型、条目数量、空间和布局校验。
- 恢复使用同盘暂存、同步事务日志和目录交换；失败回滚，冷启动先回滚未完成事务。保留恢复前目录；插件依赖尝试离线重建，失败则回滚。提交后 Harness 启动失败单独报告，不把已恢复数据说成失败回滚。
- 原盘救援先等待 QEMU 实际退出，再复制 raw 和生成 SHA256；不删除原盘、不允许在原进程重启 QEMU。冷启动保留并移走残留 .git/index.lock 后才开放 Harness。
- 完整备份/恢复申请 iOS 26+ BGContinuedProcessingTask，使用实际传输字节更新进度；不支持或被拒绝时使用有限后台时间。系统到期取消宿主传输，不承诺后台永久执行。

## 自动验证

Swift 核心 19 项、guest 14 项以及 iOS Simulator 与无签名 iPhoneOS Release 编译通过。guest 测试覆盖完整数据往返、排除项、恶意链接、损坏归档、目录交换失败、冷启动中断回滚、写入者退出和残留 Git 锁；Swift 测试覆盖上传前校验、恢复状态和 VM 不重复启动。

`runtime/tests/boot-acceptance.py` 在 Linux QEMU 的新建临时 8 GiB 用户盘上验证：socketpair/QMP、官方鉴权与真实页面、时间同步、转发修复、官方 CLI 安装并组合自制插件、IPv4/IPv6 HTTP 与 WebSocket 往返、ext4 一致备份、恢复前后 Harness 重新就绪、数据恢复、坏归档保留有效数据、项目回收与清空。脚本只输出固定结果及状态，不输出串口全文或启动凭据。运行命令：`python3 runtime/tests/boot-acceptance.py <guest 资源目录>`，需要 Linux aarch64 QEMU 和可用的固定测试端口。

这些结果证明隔离虚拟机中的运行流程；没有代替 iPad 后台、签名、模型调用和交互验收。

## 下一次真机集中验证

一次覆盖安装后，在同一包完成下列记录，不为每个小项重新安装。

1. 项目和回收站行菜单打开后文字仍可见；删除、清空后官方侧栏工作区消失，向旧归档会话发送消息不会重建被删目录。
2. 完成 S 仓库安装、测试、提交和推送；Git token 由用户在终端提示时输入。项目开发启动不超过 2 分钟，HMR 不超过 15 秒。
3. 官方安装一个社区插件和自制 hello 插件，由模型各调用一次；复开后仍可用。软件/外接键盘、中文组合输入、横竖屏预览及关闭预览不停止 VM。
4. 流式回答、停止生成、API Key 与会话恢复；短后台、30 分钟和至少 8 小时后台分别记录结果。存活 guest 回前台目标 10 秒内恢复，时间误差不超过 2 秒；系统强杀后复用原盘冷启动。
5. 完整 tar+SHA256 导出、恢复及坏归档拒绝；救援 raw 导出不删除原盘；主动备份中切后台，记录系统任务是否支持、是否完成或中断。
6. 同身份覆盖安装和重签后项目、会话、配置、Git 历史及插件仍在；固定 Landlock 探针通过。换身份导出恢复、他人重签属于后续分发验证，未执行不得登记通过。
