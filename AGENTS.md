## Agent skills

### 接手开发

新会话或新 Agent 开始本项目工作时，先读 `docs/agents/handoff.md`，再按任务分支读取其中的真机工具或验收记录。结束工作时更新交接的当前状态、已验证结果、未完成项和下一步；私有设备、签名及原始证据留在忽略的 `build/` 中。

### Issue tracker

Issues and specs live in GitHub Issues for `lvivvde/deepseek-harness-ipad`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
